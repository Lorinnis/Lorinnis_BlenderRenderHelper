# Blender Render Queue Add-on

[English](README.md) | [简体中文](README_CN.md)

- This add-on assembles multiple `.blend` project files into a render queue and renders them in batch.

## Features

- Batch rendering of multiple finished `.blend` projects
- Optional automatic system shutdown once the queue has finished

## Compatibility

- Minimum Blender version: 2.93
- Operating system: Windows only — the add-on relies on generated `.bat` scripts, which are Windows-specific

## Installation

1. Download the `.py` file.
2. Open Blender → Edit → Preferences → Add-ons.
3. Click **Install** in the upper-right corner and select the downloaded `.py` file.
4. Locate the add-on in the list and enable it with the checkbox.
5. In the 3D Viewport, press **N** to open the sidebar and switch to the **Render Helper** (渲染助手) tab.

## Usage

1. Open the 3D Viewport sidebar and switch to the **Render Helper** (渲染助手) tab.
2. Select a working directory. No other `.blend` files should be placed in this directory.
3. Add the current project to the queue.
4. Start rendering.
