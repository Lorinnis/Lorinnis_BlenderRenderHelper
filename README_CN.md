# Blender 渲染队列插件

[English](README.md) | [简体中文](README_CN.md)

- 此插件可将多个 blend 工程文件组成渲染队列，批量渲染。

## 功能介绍

- 制作完多个 blend 工程后，可批量渲染
- 可选择完成任务后自动关机

## 兼容性

- Blender 最低版本：2.93
- 系统环境：由于涉及到 bat 脚本，此插件仅支持 Windows 系统使用

## 安装方式

1. 下载 `.py` 文件
2. 打开 Blender → 编辑 → 偏好设置 → 插件
3. 点击右上角「安装」，选中下载好的 `.py` 文件
4. 在列表找到插件名称，勾选启用
5. 在 3D 视图按 **N** 键打开侧边面板，切换到 **渲染助手** 标签页使用

## 使用说明

1. 打开 3D 视图侧边栏，切换到 **渲染助手** 标签页
2. 选择工作目录，此目录下不要有其他 blend 文件
3. 添加当前工程到队列
4. 开始渲染
